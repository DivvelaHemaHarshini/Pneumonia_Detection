# 🫁 Pneumonia Detection Using Deep Learning

An AI-powered Pneumonia Detection System that uses Deep Learning and Machine Learning models to analyze medical data, including chest X-ray images and lung sound recordings, to assist in identifying possible pneumonia-related conditions.

## 📌 Project Overview

Pneumonia is a respiratory infection that affects the lungs and can cause breathing difficulties. Early identification can help support timely medical evaluation.

This project uses trained deep learning models to analyze chest X-ray images and lung sound recordings. It provides an AI-based approach to assist in pneumonia detection and respiratory health analysis.

**Note:** This project is intended for educational and research purposes only. It is not a substitute for professional medical diagnosis.

## ✨ Features

- 🩻 **Chest X-ray Analysis:** Uses deep learning models to analyze chest X-ray images.
- 🫁 **Pneumonia Detection:** Uses trained neural networks to identify possible pneumonia patterns.
- 🎵 **Lung Sound Analysis:** Analyzes respiratory sound recordings.
- 🤖 **AI-Based Prediction:** Uses trained machine learning and deep learning models.
- 🔍 **X-ray Validation:** Includes models for validating X-ray images.
- 📊 **Multiple Models:** Integrates different trained models for medical data analysis.

## 🧠 Machine Learning Models

The project includes the following trained models:

| Model Name | Purpose |
|---|---|
| `model_pneumoniaNet.h5` | Pneumonia detection |
| `model_resnet.h5` | Deep learning image analysis |
| `lung_sound_model.h5` | Lung sound classification |
| `lung_sound_model_v2.h5` | Updated lung sound model |
| `xray_validator_model.h5` | X-ray image validation |
| `xray_validator_modell.h5` | Additional X-ray validation model |

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/DivvelaHemaHarshini/Pneumonia_Detection.git
```

### 2. Navigate to the Project Directory

```bash
cd Pneumonia_Detection
```

### 3. Install Git LFS

The trained model files are stored using Git Large File Storage.

Install Git LFS from:

https://git-lfs.com/

Initialize Git LFS:

```bash
git lfs install
```

Download the model files:

```bash
git lfs pull
```

### 4. Create a Virtual Environment

```bash
python -m venv myenv
```

Activate it on Windows:

```bash
myenv\Scripts\activate
```

### 5. Install Dependencies

If a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

Otherwise, install the dependencies specified by your project.

### 6. Run the Application

Run the application using its configured entry point.

For example, if it is a Django application:

```bash
python manage.py runserver
```

Open the local URL displayed in your terminal.

## 🔬 Working Methodology

1. Input medical data such as a chest X-ray image or lung sound recording.
2. The application processes the uploaded input.
3. The corresponding trained deep learning model analyzes the input.
4. The model generates a prediction.
5. The application displays the prediction result to the user.
